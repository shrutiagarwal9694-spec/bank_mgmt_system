🏦 AMS Bank Management System

A fully functional Bank Management System built using HTML, CSS, JavaScript, and PHP.
This project simulates essential banking operations like account management, balance checking, fund transfers, deposits, withdrawals, and transaction tracking — all through a simple, clean, and user-friendly interface.

🚀 Features
🔐 User Authentication

Secure login & signup system

Session handling for users

💳 Account Operations

Create new bank accounts

View account details

Change password

Logout securely

💰 Bank Transactions

Deposit money

Withdraw money

Transfer funds between accounts

View real-time balance

📜 Transaction History

Track deposits, withdrawals, and transfers

Organized and easy-to-read records

🛠️ Admin Features

Admin login

Access to all user account details

Monitor transaction records

🧰 Tech Stack
Layer	Technologies Used
Frontend	HTML, CSS, JavaScript
Backend	PHP
Database	MySQL
Server Env	XAMPP / WAMP / LAMP
