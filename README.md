# 🏦 AMS Bank Management System

A highly secure, robust, and feature-rich **Bank Management System** web application developed using **HTML5, CSS3, JavaScript (ES6), PHP**, and **MySQL**. This application simulates fully functional modern banking workflows including self-service customer dashboards, secure fund transfers, automated OTP-based withdrawals, and a comprehensive administrative command center.

---

## 📸 Interface Preview

The interface features custom-designed backgrounds, interactive hover animations, and a dynamic 3D-flipping profile card for a premium and immersive user experience.

*   **Interactive Landing:** A high-end welcome screen featuring a glowing, animated brand logo with modern CSS effects.
*   **Dynamic Client Portal:** A custom-styled dashboard containing quick-access banking controls and interactive client profile cards.
*   **Dual Portal Access:** Distinct, secure gateways tailored for standard clients and banking administrators.

---

## 🚀 Key Features

### 👤 Customer Portal
*   **Interactive Dashboard (`bank_mgmt.php`):** View user profiles via a 3D rotating card showing user photo, DOB, address, contact, and account number.
*   **Real-time Balance Inquiry (`check_Balance.php`):** Securely check account balance after verifying the account's 4-digit Security PIN.
*   **Secure Fund Transfer (`Transfer.php`):** Instantly transfer money to any valid account number. Validates recipient account presence, checks sender balance, and securely completes transactions using the Security PIN.
*   **Smart Cash Withdrawals (`debit_Amount.php`):** Initiate withdrawal requests from the dashboard. Generates a secure, unique, and temporary 4-digit OTP for secure counter cash dispatching.
*   **Dynamic Passbook (`History.php`):** A real-time transaction ledger mapping transaction history (Deposits, Withdrawals, Transfer-Debits, and Transfer-Credits) with recipient names, dates, times, and status.
*   **Self-Service Password Reset (`forgot_password.php` & `change_Password.php`):** Recover and change password securely using pre-registered security questions.

### 🛡️ Administrative Portal
*   **Protected Admin Workspace (`admin_login.php`):** Restricted dashboard accessed via admin credentials to run branch activities.
*   **Customer Registration (`sign_up.php`):** Create new client accounts, upload profile pictures, set security questions, passwords, transaction PINs, and auto-generate unique 10-digit account numbers.
*   **Cash Deposit Desk (`credit_Amount.php`):** Add funds directly to any client account using their account number.
*   **Cash Withdrawal Terminal (`withdraw.php`):** Verify OTP and PIN generated by clients to securely execute cash payouts and update statuses to successful.
*   **Central Customer Registry (`admin_page.php`):** Monitor all registered clients, review total amounts credited, debited, and transferred per account, and access any user's real-time transactional history ledger.

### 🔒 Built-in Security Controls
*   **Anti-Inspect Protections:** Hardened front-end script preventing context-menu (right-click) actions, page source viewing (`Ctrl + U`), saving (`Ctrl + S`), print (`Ctrl + P`), tab index navigation, and Developer Tools inspection (`F12`).
*   **Secure Sessions:** Server-side PHP session state validations preventing unauthorized URL browsing.
*   **Safe SQL Execution:** Built with MySQLi prepared statements and parameterized inputs to block SQL Injection vulnerabilities.

## 🗄️ Database Schema & SQL Setup

To set up the database locally, create a database named `kshatri1_Chauhan` (or rename the database parameter inside `connection.php`) and execute the following SQL schema statements:

```sql
CREATE DATABASE IF NOT EXISTS `kshatri1_Chauhan`;
USE `kshatri1_Chauhan`;

-- 1. Table structure for Bank_Customer
CREATE TABLE IF NOT EXISTS `Bank_Customer` (
  `Name` varchar(100) NOT NULL,
  `Father_Name` varchar(100) NOT NULL,
  `DOB` date NOT NULL,
  `E_mail` varchar(100) NOT NULL,
  `Security_Pin` varchar(10) NOT NULL,
  `Contact` varchar(15) NOT NULL,
  `Address` text NOT NULL,
  `Sec_Q` varchar(255) NOT NULL,
  `Answer` varchar(255) NOT NULL,
  `Password` varchar(255) NOT NULL,
  `Account_No` varchar(20) NOT NULL,
  `Photo` varchar(255) NOT NULL,
  `Creditted_Amount` double DEFAULT 0.00,
  `Debitted_Amount` double DEFAULT 0.00,
  `Transfered_Amount` double DEFAULT 0.00,
  `Current_Balance` double DEFAULT 0.00,
  PRIMARY KEY (`E_mail`),
  UNIQUE KEY `Account_No` (`Account_No`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 2. Table structure for History (Passbook records)
CREATE TABLE IF NOT EXISTS `History` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `Account_No` varchar(20) NOT NULL,
  `Statement` varchar(100) NOT NULL,
  `Transaction` double NOT NULL,
  `Recipient` varchar(100) NOT NULL,
  `Date` date NOT NULL,
  `Time` time NOT NULL,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 3. Table structure for Withdraw (OTP management)
CREATE TABLE IF NOT EXISTS `Withdraw` (
  `OTP` varchar(10) NOT NULL,
  `Amount` double NOT NULL,
  `Statement` varchar(50) NOT NULL DEFAULT 'Pending',
  `Pin` varchar(10) NOT NULL,
  PRIMARY KEY (`OTP`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## ⚙️ Installation & Deployment

Follow these simple steps to host and run the application locally:

### 1. Set Up Environment
Download and install local server software such as **[XAMPP](https://www.apachefriends.org/)**.

### 2. Clone/Copy Code
Copy the project folder `ams-bank-mgmt-main` and paste it inside the root directory of your server:
*   For XAMPP: `C:\xampp\htdocs\`
*   For WAMP: `C:\wamp\www\`

### 3. Setup Database
1.  Start the **Apache** and **MySQL** modules from the XAMPP Control Panel.
2.  Open your browser and navigate to `http://localhost/phpmyadmin/`.
3.  Click on the **SQL** tab.
4.  Paste the SQL commands provided in the **Database Schema & SQL Setup** section above and click **Go**.

### 4. Configure Database Connection
Open `connection.php` and update configuration parameters to match your database settings:
```php
<?php
    $servername = "localhost";
    $username = "root";             // Use your local MySQL user (default is root)
    $password = "";                 // Use your local MySQL password (default is empty)
    $database = "kshatri1_Chauhan"; // Matches the database name
    
    $conn = new mysqli($servername, $username, $password, $database);
    if ($conn->connect_error) {
        die("Connection failed: " . $conn->connect_error);
    }
?>
```

### 5. Access the Web Application
Open your web browser and navigate to:
```text
http://localhost/ams-bank-mgmt-main/index.php
```
